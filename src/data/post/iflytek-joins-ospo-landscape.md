# 科大讯飞加入 TODO Group OSPO 全景图

近日，科大讯飞正式加入 TODO Group OSPO 全景图（OSPO Landscape），被收录在 OSPO Adopter（OSPO 采纳者）分类下，与 GitHub、Honda、IBM、Intel 等全球领先企业和组织并列，成为 OSPO 实践者社区的一员。🎉

![科大讯飞在开源治理、开源项目管理和社区参与等方面的实践获得了 TODO Group 和国际开源社区的认可](~/assets/images/iflytek-ospo-landscape.png)

收录条目可在 OSPO Landscape 官网查看：[landscape.todogroup.org](https://landscape.todogroup.org/?item=ospo-adopter--ospo-ad%D0%BEpter--iflytek-adopter)

## 关于 TODO Group 与 OSPO 全景图

[TODO Group](https://todogroup.org/) 是一个由 Linux 基金会托管的开放、中立的社区，致力于帮助组织更好地采纳和管理开源项目。社区通过创建共享资源和最佳实践指南，帮助企业在开源管理、AI 治理等领域建立规范化的流程和实践。

[OSPO 全景图](https://landscape.todogroup.org/)（OSPO Landscape）是 TODO Group 推出的一项重要资源，旨在为开发者和企业提供一张开源项目办公室（OSPO）生态的资源地图。全景图收录了拥有 OSPO 的组织、支持 OSPO 运作的工具和资源，帮助用户快速了解 OSPO 生态全貌。**OSPO Adopter**（OSPO 采纳者）分类专门收录已建立开源项目办公室的组织，涵盖企业、政府机构、学术机构等各类组织。

## 什么是 OSPO？

**OSPO（Open Source Program Office，开源项目办公室）**是组织内部负责协调和管理开源活动的专门团队或部门。OSPO 通常承担以下职责：

- **开源策略制定**：建立组织的开源使用、贡献和发布政策
- **合规管理**：确保开源软件的使用符合许可证要求
- **社区参与**：协调组织与开源社区的互动和贡献
- **生态建设**：推动组织内部开源项目的孵化和发展
- **风险管理**：识别和管理开源相关的法律、安全和技术风险

越来越多的全球化企业认识到 OSPO 在开源治理中的关键作用，通过建立 OSPO 来系统性地管理组织的开源活动。

## 加入 OSPO 全景图的意义

进入 OSPO 全景图，意味着科大讯飞在开源治理、开源项目管理和社区参与等方面的实践获得了 TODO Group 和国际开源社区的认可。作为 OSPO Adopter，讯飞将与全球领先的 OSPO 实践者共同交流经验、分享最佳实践。

这也是讯飞开源生态在国际社区取得的又一重要进展。此前，Astron Agent 已进入 CNCF 云原生全景图，Astron SkillHub 加入了 Agentic AI Foundation（AAIF）。讯飞开源正以更加开放和规范的姿态，融入全球开源治理体系。

## 科大讯飞的开源实践

科大讯飞自 2019 年起系统性推进开源工作，先后在 [GitHub](https://github.com/iflytek) 和 [Gitee](https://gitee.com/iflytek) 上建立了开源社区，开放了涵盖语音识别、自然语言处理、计算机视觉等 AI 核心技术的项目矩阵。

近年来，讯飞开源生态持续壮大：

- **[Astron Agent](https://github.com/iflytek/astron-agent)**：企业级智能体编排平台，已进入 CNCF 云原生全景图，GitHub Stars 超过 8,600
- **[Astron Landscape](https://opensource.iflytek.com/#project-landscape)**：全球首个企业级智能体开源项目矩阵全景图
- **[SkillHub](https://github.com/iflytek/SkillHub)**：智能体技能注册中心，已加入 Agentic AI Foundation
- **[iFly-Skills](https://github.com/iflytek/iFly-Skills)**：官方智能体技能库

未来，科大讯飞将继续深化开源实践，与全球开源社区共同推动 AI 技术的开放与创新。
